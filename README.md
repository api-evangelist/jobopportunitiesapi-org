Job Opportunities API aggregates employer‑direct job listings with per‑field provenance, allowing users to verify each data point before spending. The platform pulls from career pages, government feeds, and direct employer submissions, excludes third‑party aggregators, and continuously re‑checks listings for accuracy. It provides free read and post access via a public API, offering detailed job metadata, confidence scores for derived categories, and transparent source attribution. As of November 2026, over 2.4 million live openings from 151 k employers are available, with daily updates and open licensing for developers.

**Areas:** Job · Employment Data · Data Provenance · Job Board · AI Agents

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Job Opportunities API: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
